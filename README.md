# OficinaPro-SaaS 🛠️

ERP SaaS para oficinas mecânicas, desenvolvido em **Streamlit** com banco de dados **SQLite**.  
O sistema oferece gestão completa de ordens de serviço, estoque, financeiro e administração, com identidade visual inspirada no estilo Nubank.

## 🚀 Funcionalidades principais
- 🔐 **Login seguro** com controle de sessão e perfis de acesso (Admin, Gerente, Mecânico).
- 📋 **Ordens de Serviço** integradas ao estoque e financeiro.
- 📦 **Gestão de Estoque** com alerta de reposição e validade de peças.
- 💰 **Financeiro** com cálculo de receita, custos e lucro líquido real.
- 👥 **Administração** de colaboradores, reset de senhas e backup simulado em nuvem.
- 👑 **Gestão SaaS** com planos e status de assinatura.

## 🖥️ Tecnologias utilizadas
- [Streamlit](https://streamlit.io/) para interface web.
- [SQLite](https://www.sqlite.org/) para persistência de dados.
- [Pandas](https://pandas.pydata.org/) para manipulação e análise.
- [Python](https://www.python.org/) como linguagem principal.
